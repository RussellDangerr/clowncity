# Clown City v0.2.0 — The Unicycle Rework

v0.2.0 reimagines the core: the free-moving platformer character is now **Poko
the Clown on a unicycle** — a bidirectional **auto-runner**. Poko is always
moving; the player only chooses direction and jump. This also makes the game
**mobile-playable** for the first time (3-input swipe/tap scheme). Art is still
the rect-fallback placeholder — this release is about feel and systems.

## New

### Unicycle momentum (auto-runner)
At level start Poko eases from a standstill up to full speed over ~1.5s, then
cruises. There is no "stand still" — you are always rolling left or right. A
`ramp → cruise → brake` state machine in `player.js` drives horizontal velocity
(`approach()` toward a target each tick) and replaces the old accel/friction model.

### Weighty turnaround + wheel-throw combat
Swiping against your travel direction starts a **weighty reversal**: decelerate,
a brief pause at zero, then accelerate the other way (~0.36s end to end). On that
swipe the wheel **kicks out in the OLD direction** — the physical braking lunge a
unicyclist makes to stop — and that lunge is the **attack hitbox**. So you drive
at an enemy and reverse at the moment of contact to whack it, then peel away.
Enemies are also killed by a **stomp** from above (with a hop). Side contact is
lethal. Poko's sprite always faces the same way, so a back-side hit reads as luck.

### Swipe / tap mobile controls
`input.js` gains touch handling: horizontal **swipe = steer** (sticky direction,
multi-touch tracked by identifier), **tap = jump**. Keyboard parity is kept
(← →/A D steer, Space/↑/W jump) for desktop. Menus (title, level select, complete,
win) are tap/swipe navigable. `index.html` adds `touch-action: none` + viewport
locks so mobile browsers don't hijack the gestures, and the AudioContext now
resumes on touch.

### Treadmill surfaces
Replace ice. While grounded on a treadmill, top speed is capped at 0.5 and
momentum is bled toward the cap (non-directional). New `T` tile + scrolling-belt visual.

### Design system
New `js/tokens.js` — a single source of truth for colour, a monospace type scale,
spacing, and motion constants — with ~90 previously-hardcoded values across the
codebase refactored to use it. Full audit + reference in `DESIGN-SYSTEM.md`
(token-coverage score 38 → 86 / 100).

## Removed / changed
- Cut: air-dash, wall-slide, wall-jump, sponge grab/stick, variable jump height,
  spikes, sawblades, bouncy and breakable tiles. Jump is now a single fixed-height tap.
- All three levels rebuilt as lean "unicycle track" layouts: wide floors, jumpable
  pits, a treadmill stretch, patrol monsters, a ferry platform, gems, checkpoint, goal.
- Camera lookahead now leads **travel direction** instead of facing (facing is frozen).

## How to play
Check out `v0.2.0` and open `index.html` in a browser. No build step.

**Controls:** swipe (or ← →) to steer, tap (or Space) to jump. Reverse into a
monster to whack it, or stomp it from above. Don't fall in the gaps.
